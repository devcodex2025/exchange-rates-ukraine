# Currency icons

Outline currency glyphs (UAH, USD, EUR, GBP, PLN, CHF) copied from
[Tabler Icons](https://github.com/tabler/tabler-icons) v3.50 — MIT License, © Paweł Kuna.
Source files upstream: `icons/outline/currency-{hryvnia,dollar,euro,pound,zloty,frank}.svg`.

The UI uses the same path data inlined in `src/components/ui/currency-glyph.tsx`
(so the glyphs inherit the theme color via `currentColor`); this folder keeps the
standalone copies for docs, READMEs or CSV exports.
